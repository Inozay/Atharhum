# أَثَرُهُم — Knowledge Trust Infrastructure

نواة تطبيق ويب عربية (RTL) لإدارة سجلات المعرفة، ربط الأصل بمصدره، عرض الحقوق والمراجعة ودور AI، التحقق عبر رابط/QR، رحلات التعلم، إعادة الاستخدام مع الإسناد، التعاون المؤسسي، الإبلاغ عن الانحراف، التصحيح وإصدارات السجل، وقياس التفاعلات.

## تشغيل محلي

المتطلبات: Python 3.11+.

```bash
python -m pip install -r requirements.txt
python -m py_compile server.py
python server.py
```

ثم افتح `http://localhost:8080`. لتغيير المنفذ استخدم متغير `PORT`.

بيانات الدخول التجريبية:

- البريد: `demo@atharhum.org`
- كلمة المرور: `Atharhum2026!`

يُنشأ ملف SQLite تلقائيًا في `data/atharhum.db`. لا ترفع قاعدة البيانات أو الأسرار إلى GitHub.

## نشر صحيح على Render — مهم

هذا المشروع **Python Web Service وليس Docker**. سبب خطأ `open Dockerfile: no such file or directory` هو أن الخدمة كانت مضبوطة على Docker.

الطريقة الموصى بها:

1. فك ضغط الحزمة على جهازك.
2. ارفع **محتويات المجلد** إلى جذر مستودع GitHub، بحيث يظهر `server.py` و`render.yaml` و`requirements.txt` في الصفحة الرئيسية للمستودع. لا ترفع ملف ZIP وحده ولا تضع كل الملفات داخل مجلد فرعي إضافي.
3. في Render أنشئ **New + → Blueprint** من المستودع، أو أنشئ Web Service جديدة واختر Runtime = **Python** وليس Docker.
4. إعدادات البناء والتشغيل:
   - Build: `pip install -r requirements.txt && python -m py_compile server.py`
   - Start: `python server.py`
   - Health check: `/health`
5. يحتوي `render.yaml` على قرص دائم لمسار قاعدة البيانات. استخدم خدمة واحدة عند الاعتماد على SQLite/القرص المحلي الدائم.
6. إذا تغيّر اسم خدمة Render، حدّث `PUBLIC_BASE_URL` إلى عنوان الخدمة المنشور، ثم أعد النشر لتوليد رموز QR على العنوان الصحيح.
7. بعد النشر افتح `https://YOUR-SERVICE.onrender.com/health` وتأكد أن النتيجة تحتوي `"ok": true`، ثم اختبر الصفحة الرئيسية ورابط `/verify/ATH-TANZIL-001`.

لا تغيّر إعدادات الخدمة القديمة المضبوطة على Docker؛ أنشئ خدمة Python جديدة أو استخدم Blueprint لتطبيق `render.yaml`.

## ما الذي يعمل

- واجهة RTL: الرئيسية، سجل المعرفة، جواز المعرفة، التحقق، التعلم، الأثر، Evidence Assistant، مساحة المؤسسة.
- مصادر ومواد مرجعية أولية؛ وجود سجل مصدر لا يعني شراكة أو اعتمادًا من الناشر.
- SQLite، جلسات دخول، سجل أحداث، إنشاء أصل، طلب تعاون، إعادة استخدام مع attribution، الإبلاغ عن انحراف والتصحيح بإصدار جديد.
- QR يولد من `PUBLIC_BASE_URL` ويُخدم عبر `/qr/{ID}.png`.
- لوحة الأثر تحسب اكتمال السجلات من حقول المصدر والحقوق والمراجعة وAI والإصدار؛ ليست درجة للحقيقة.
- Evidence Assistant الحالي **مساعد قواعد/سجل مقيد** وليس اتصالًا بنموذج لغوي خارجي. لا يُدّعى أنه RAG أو LLM فعلي.

## حدود النسخة

هذه نواة إنتاجية قابلة للتجربة، وليست بعد SaaS مؤسسيًا متعدد المستأجرين. قبل استخدام مؤسسي واسع يلزم تنفيذ PostgreSQL، عزل المؤسسات، SSO، حماية/تحديد معدل الطلبات، مراقبة، CI/CD، تكامل AI/RAG فعلي مع مصادر، وتوقيع منشأ تشفيري. لا تستخدم كلمة المرور التجريبية في خدمة عامة.
