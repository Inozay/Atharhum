# Impact event dictionary

| Event | Meaning | Privacy rule |
|---|---|---|
| CONTENT_VIEWED | A content page was viewed | anonymous/session only |
| QR_SCANNED | Verification QR was scanned | anonymous/session only |
| CONTENT_VERIFIED | User reached the verified passport | anonymous/session only |
| SOURCE_VIEWED | Source record opened | anonymous/session only |
| JOURNEY_STARTED | Learning journey started | anonymous/session only |
| JOURNEY_STEP_COMPLETED | A journey step completed | anonymous/session only |
| JOURNEY_COMPLETED | Journey completed | anonymous/session only |
| CONTENT_REUSED | Another organization reused content | organization-level |
| COLLABORATION_REQUESTED | Collaboration requested | organization-level |
| COLLABORATION_ACCEPTED | Collaboration accepted | organization-level |

**Do not infer sensitive religious identity.** Geography and language should be aggregated; names, phone numbers and email are not required for basic impact analytics.
