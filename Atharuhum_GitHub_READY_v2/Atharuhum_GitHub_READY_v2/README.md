# Atharuhum — From Trusted Knowledge to Measurable Impact

**أَثَرُهُم** is an AI-enabled trust and impact layer for Islamic knowledge organizations.

It connects:

**CONTENT → TRUST → ENGAGEMENT → LEARNING → MEASURABLE IMPACT**

## What is working in this release?

- Premium responsive product interface
- Content Identity with a persistent Atharuhum ID
- QR-based content verification
- Content Passport / provenance lifecycle
- Human-review and source-safety boundary
- Source-grounded AI demonstration with citations
- Structured learning journey
- Privacy-preserving event tracking
- Live Impact Funnel
- AI Impact Intelligence recommendations
- Source Registry
- SQLite event store for a lightweight, reproducible hackathon demo
- One-service Docker deployment: FastAPI serves both API and frontend
- Health endpoint for deployment monitoring

## Product demo flow

1. Open the public product.
2. Click **Experience demo**.
3. Watch the Impact Funnel update from a real event.
4. Open **Verify a content record**.
5. Inspect the Content Passport and source record.
6. Try the source-grounded AI questions.
7. Complete the five-step Learning Journey.
8. Return to Impact to see the evidence change.

## Architecture

```text
Browser
  │
  ▼
Atharuhum Web App (FastAPI + HTML/CSS/JS)
  ├── Content Identity
  ├── Verification + QR
  ├── Content Passport
  ├── Source Registry
  ├── Learning Journey
  ├── Impact Event Engine
  └── Source-grounded AI demo
          │
          ▼
      SQLite event store
```

For production scale, replace SQLite with PostgreSQL, add authentication/RBAC, durable storage, rate limiting, monitoring, audit logs, backups, and a curated production source registry.

## Local run — easiest

### Docker

```bash
docker compose up --build
```

Open:

`http://localhost:8000`

Health:

`http://localhost:8000/api/health`

API documentation:

`http://localhost:8000/docs`

### Python

```bash
cd backend
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

Then open `http://localhost:8000`.

## Public deployment

The recommended hackathon deployment is a **single Render Web Service using the root Dockerfile**. This keeps the frontend and backend on the same origin, so the API and QR verification work without localhost configuration.

See `DEPLOYMENT.md`.

## Important demo integrity note

The dashboard's baseline metrics are explicitly labeled demonstration data. Live events generated by the user are added to that demonstration baseline so judges can observe the product's event engine working in real time.

The included source registry contains a clearly labeled demo registry record. Before any public production use, replace it with verified sources whose publication and licensing status have been checked by the responsible institution.

## AI safety boundary

Atharuhum is **not an autonomous Mufti** and does not issue independent fatwas. The AI layer is designed for retrieval, explanation, navigation, translation/localization, learning-path generation, and impact intelligence over approved/curated knowledge. Sensitive or disputed religious answers should remain subject to qualified human review.
