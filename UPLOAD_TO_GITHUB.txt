أَثَرُهُم v3 — طريقة الاستبدال في Atharhum-pro

1) فك ضغط Atharhum_v3_final.zip.
2) افتح مجلد atharhum_v3.
3) في مستودع Atharhum-pro، استبدل محتويات المشروع بهذه الملفات.
4) تأكد أن Dockerfile وrender.yaml موجودان في الجذر.
5) ادفع التغييرات إلى main.
6) Render سيعيد البناء من Docker تلقائياً.
7) Health Check Path: /api/health.
8) لا تحتاج Node أو npm أو React.

بعد النشر اختبر الرحلة الكاملة:
المعرفة → جواز المحتوى → التحقق → خريطة السند → المساعد → التعلم → الأثر.

مهم:
- لا تضع كلمات Demo / Judge / 90 seconds داخل المنتج.
- بيانات المعرفة الحالية بيانات منتج تجريبية وليست مصادر علمية حقيقية.
- بيانات Impact التأسيسية تجريبية وليست دراسة أثر.
