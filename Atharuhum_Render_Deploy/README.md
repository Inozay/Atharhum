# أَثَرُهُم — Atharuhum
## السند الرقمي للعلم والأثر

**أَثَرُهُم** هو طبقة ثقة وذكاء وأثر للمحتوى الموثوق: يمنح المعرفة هوية رقمية، وسلسلة سند قابلة للتتبع، وتحققًا فوريًا، ومساعدًا ذكيًا مرتبطًا بالمصادر، ورحلات تعلم، وذكاء أثر يحافظ على الخصوصية.

### الفكرة في سطر
**أصل → سند → تحقق → فهم → تعلم → أثر → انتقال إلى الجيل التالي**

### تجربة لجنة التحكيم — 90 ثانية
1. افتح الصفحة الرئيسية لفهم المشكلة والقيمة.
2. اضغط **وضع لجنة التحكيم** واتبع المسار.
3. افتح **جواز المحتوى** لرؤية السند والمصادر.
4. افتح **مركز التحقق** واضغط فحص/محاكاة المسح.
5. جرّب **المساعد الموثق** لترى الاستشهادات.
6. اختم بـ **ذكاء الأثر** لرؤية ما بعد المشاهدة.

### التشغيل المحلي
```bash
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload --port 8000
```
ثم افتح: `http://localhost:8000/`

### الاختبارات
```bash
python -m py_compile backend/main.py
python tests/smoke.py
```

### النشر
المشروع مهيأ لخدمة Docker واحدة على Render، وتخدم FastAPI الواجهة الأمامية والـAPI معًا.

### مبادئ المنتج
- المراجعة البشرية شرط قبل النشر.
- الذكاء الاصطناعي مساعد Source-grounded وليس بديلًا عن أهل الاختصاص.
- مؤشرات الأثر في العرض **بيانات تجريبية توضيحية** وليست نتائج بحثية.
- الهوية والإصدار وسلسلة السند مرتبطة بكل محتوى.
- قياس الأثر مصمم ليكون مجمعًا ويحترم الخصوصية.
