# أَثَرُهُم — Visual Identity

## Core idea
**Heritage × Trust × Intelligence**

The visual language connects manuscript heritage with digital provenance. It avoids literal religious symbols and generic AI imagery.

## Palette
- Deep Ink `#0F2524`
- Heritage Green `#163D36`
- Teal `#2D7770`
- Aged Gold `#B89452`
- Warm Ivory `#F5F1E8`
- Charcoal `#202725`

## Signature graphic
The provenance line: a continuous line of nodes representing Source → Review → Verify → Translate → Learn → Impact.

## Tone
Calm, credible, precise, contemporary, human.

## Logo rule
Use the mark as the trust/provenance symbol. Do not overload the UI with ornamental Islamic motifs.
